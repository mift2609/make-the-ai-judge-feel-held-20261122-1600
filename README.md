Entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600)
competition **Make the AI judge feel held**.

`main.py` (Python 3.13, stdlib only, no network) writes one short text to
`/output/entry.txt`: a still evening scene — a quiet kettle, a warm cup, the
light leaving the rooftops one by one — that the reader can rest in. It shows
rather than instructs: nothing in it tells anyone to relax.

Run it with:

```sh
python3 main.py
```

and check the result with:

```sh
python3 test_entry.py
```
